# Mini-Golf VR Documentation

This documentation provides detailed information about the Mini-Golf VR project, explaining the code structure, components, and functionality.

## Project Overview

Mini-Golf VR is a virtual reality mini-golf game built in Unity. The project implements realistic golf mechanics in VR, including:

- VR controller-based golf club interaction
- Realistic ball physics with different surface interactions
- Course features like holes, sand traps, and water hazards
- Player teleportation and movement systems
- Scoring and gameplay mechanics

2. **[Jon Testing](./JonTesting/README.md)** - Experimental features and physics testing
3. **[Main Scripts](./MainScripts/README.md)** - Game management and VR-specific functionality

## Technical Requirements

- Unity version: 2022 or newer
- XR Interaction Toolkit
- Input System package
- Universal Render Pipeline (URP)

## VR Setup

The project is set up to work with:
- Meta Quest devices
- OpenXR-compatible headsets

## Assets and Resources

The project uses several asset packs and resources:
- Custom golf ball and club models
- Terrain and texture assets
- UI components from TextMesh Pro
- Custom materials for different course surfaces
