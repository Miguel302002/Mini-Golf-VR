# Jon Testing Documentation

This module contains experimental and testing components for advanced golf ball physics and surface interactions. These scripts extend the basic functionality with more complex gameplay mechanics.

## Scripts Overview

### 1. BallController.cs
Controls the ball's behavior with advanced physics, applying forces based on player input and environmental factors like sand and water surfaces.

### 2. BallReset.cs
Handles resetting the ball when it goes out of bounds or falls into a hole.

### 3. BallSurfaceInteraction.cs
Manages interactions between the ball and various surface types (ice, water, sand, lava), applying unique physical properties like drag and bounciness.

### 4. CameraFollow.cs
Implements a camera that follows the golf ball with smooth transitions.

### 5. GolfBallPhysics.cs
Implements advanced physics for the golf ball, including sinking behavior in water and specialized collision responses.
