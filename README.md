## Project Description:
### Our VR Mini Golf game offers a two level arcade-like golfing experience with intuitive VR controls and creatively designed courses. Players will explore distinct environments each with several challenges and obstacles which will provide the player with an engaging experience before passing to the next level in the story. 
## Instructions:
### 1. Download the APK either directly from the repo file or under releases
### 2. Make sure that the quest device is set for developer mode
### 3. Load the APK using the Meta Quest Developer Hub
### 3.1 In Meta Quest Developer Hub, go to the “Device Manager” tab
### 3.2 Click the "Package Manager" tab on the left sidebar
### 3.3 Click “+ Add APK” in the top-right
### 3.4 Select the APK and install
### 4. On the headset go to the Apps menu, Unknown Sources, Launch PutterVerse or the APK Build
### 5. Have fun !!!
